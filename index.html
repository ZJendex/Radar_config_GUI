A playground for exploring FMCW radar settings and their theoretical relationships. Enter waveform settings and optional targets to calculate derived values and compare targets without changing your inputs. This playground does not assume or enforce practical hardware constraints or validate hardware feasibility.

Formula Reference

Real ADC Nyquist max range
B = S * TcBandwidth from chirp slope and active chirp time.
Delta R = c / (2B)Range resolution from swept bandwidth.
Rmax real = c * Fs / (4S) = N * Delta R / 2Maximum range for real ADC sampling.
Rmax complex = c * Fs / (2S) = N * Delta RMaximum range for complex/IQ sampling.
Fs = ADC samples / TcSample rate implied by one chirp's ADC sample count.
PRI = Tc + idleChirp repetition interval.
Frame duty = Nchirps * Tc / frame periodPower-related duty cycle: fraction of each frame spent in active chirp ramps.
Delta v = lambda / (2 * Nchirps * PRI)Doppler velocity resolution.
vmax = lambda / (4 * PRI)Maximum unambiguous radial velocity.
d = lambda / 2; Delta theta ~= 2 / NrxHalf-wave receive ULA angle-resolution estimate.
